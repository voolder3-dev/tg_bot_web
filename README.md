# 💬 Telegram Support Dashboard

Веб-панель для общения с пользователями Telegram-бота прямо из браузера. Подходит для поддержки игрового сервера, сообщества или небольшого проекта.

**Общая версия панели:**  
https://voolder3-dev.github.io/tg_bot_web/

> Интерфейс общий, но каждый владелец подключает **свой Telegram-бот, Render-сервер и базу Neon**. Переписки разных владельцев хранятся отдельно.

---

## ✨ Возможности

- **Чаты:** список диалогов, история сообщений, поиск, избранное и непрочитанные.
- **Ответы:** отправка текста, ответы на сообщения, пересылка и управление сообщениями.
- **Медиа:** фотографии, видео, файлы, голосовые сообщения и стикеры.
- **Стикерпаки:** импорт целого набора по ссылке Telegram.
- **Быстрая загрузка:** медиа и стикеры сохраняются в локальном кеше браузера.
- **Удобство:** черновики, темы оформления, русский и английский языки.
- **Уведомления:** звуковые и браузерные оповещения о новых сообщениях.
- **Несколько подключений:** возможность переключаться между настроенными ботами.

## 🧩 Как это устроено

| Сервис | Назначение |
|---|---|
| **GitHub Pages** | Публикует интерфейс панели |
| **Render** | Запускает Node.js backend и связывается с Telegram |
| **Neon** | Хранит чаты и историю сообщений в PostgreSQL |
| **Telegram Bot API** | Принимает и отправляет сообщения |

GitHub Pages не запускает сервер и не хранит переписки. Для работы панели нужен отдельный backend на Render и база Neon.

# 🚀 Установка своего подключения

## 1. Создай Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`.
3. Задай имя и уникальный username, который заканчивается на `bot`.
4. Скопируй выданный **BOT_TOKEN** и сохрани его в безопасном месте.

Пользователь должен сначала открыть бота в Telegram, нажать **Start** и отправить ему сообщение. Только после этого бот сможет отвечать ему.

## 2. Создай базу Neon

1. Зарегистрируйся на [Neon](https://neon.tech/).
2. Создай проект PostgreSQL.
3. Нажми **Connect** и скопируй pooled connection string (обычно адрес содержит `-pooler`).
4. Сохрани строку — это значение для `DATABASE_URL`.

Таблицы и индексы backend создаёт автоматически. Вручную запускать SQL не требуется.

## 3. Создай сервер на Render

1. Открой [Render](https://render.com/) и выбери **New → Web Service**.
2. Подключи GitHub и выбери репозиторий `voolder3-dev/tg_bot_web`.
   - Можно использовать Fork, если нужна собственная копия исходников.
3. Укажи настройки:

| Параметр | Значение |
|---|---|
| Runtime | Node |
| Branch | `main` (или ветка твоего Fork) |
| Build Command | `npm install` |
| Start Command | `npm start` |

4. Создай сервис и скопируй его HTTPS-адрес, например `https://my-support.onrender.com`.

## 4. Добавь переменные окружения

В Render открой свой сервис → **Environment** → **Environment Variables** и добавь:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен от BotFather |
| `DATABASE_URL` | Строка подключения Neon |
| `ADMIN_API_KEY` | Собственный длинный ключ для входа в панель |
| `WEBHOOK_SECRET` | Отдельная случайная строка для проверки webhook |
| `ALLOWED_ORIGIN` | `https://voolder3-dev.github.io` |

**ADMIN_API_KEY и WEBHOOK_SECRET должны быть разными.** Для создания случайной строки можно выполнить команду в терминале с Node.js:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Запусти её два раза и используй разные результаты для двух ключей.

### Важно про ALLOWED_ORIGIN

Для общей панели указывай только домен:

```text
https://voolder3-dev.github.io
```

Не добавляй путь `/tg_bot_web/`, завершающий слеш или адрес Render. Если используешь собственный домен для интерфейса, укажи его origin вместо примера.

Нажми **Save Changes** и дождись, пока сервис запустится.

## 5. Подключи панель

1. Открой https://voolder3-dev.github.io/tg_bot_web/.
2. В поле **Адрес сервера Render** вставь адрес своего сервиса — без `/health` и других путей.
3. В поле **Ключ доступа** вставь значение `ADMIN_API_KEY`.
4. Нажми **Подключиться**.

При успешном подключении панель настроит webhook Telegram автоматически.

## 6. Проверь работу

1. Напиши своему боту в Telegram.
2. Открой панель и дождись появления чата.
3. Отправь ответ из панели.
4. Убедись, что сообщение пришло в Telegram.

Готово! Теперь можно пользоваться панелью.

## 🛠️ Частые проблемы

| Проблема | Что проверить |
|---|---|
| Сервер не запускается | Все ли пять переменных добавлены в Render и нет ли ошибок в Logs |
| Долго подключается впервые | Бесплатный Render может «усыплять» сервис после простоя; первый запрос разбудит его |
| Сайт не разрешён сервером | Проверь `ALLOWED_ORIGIN`: домен без пути и слеша в конце |
| Неверный ключ | В панели должен быть именно `ADMIN_API_KEY`, а не токен бота |
| Список чатов пустой | Нажми Start и отправь боту сообщение; проверь webhook и логи Render |
| Не отправляются сообщения | Проверь `BOT_TOKEN`, выбранный чат и ошибки Telegram в Render Logs |
| Ошибка базы данных | Проверь `DATABASE_URL` и доступность проекта Neon |
| Изменения не появились | Обнови страницу без кеша; backend и интерфейс публикуются отдельно |

Проверить доступность backend можно по адресу:

```text
https://ТВОЙ-СЕРВЕР.onrender.com/health
```

При нормальной работе сервер вернёт JSON с `"ok": true`.

## 🔐 Безопасность

- Не публикуй `BOT_TOKEN`, `DATABASE_URL`, `ADMIN_API_KEY` и `WEBHOOK_SECRET`.
- Не вставляй секреты в HTML, JavaScript, README или публичные сообщения.
- Ключ доступа хранится только в памяти текущей вкладки (`sessionStorage`); список подключений сохраняет адреса и названия, но не сами ключи.
- После закрытия вкладки ключ потребуется ввести снова. На общем компьютере обязательно нажимай «Выйти».
- У каждого владельца должны быть собственные токен, ключи, Render-сервис и база.
- В Render не отключай проверку TLS для Neon (не устанавливай `PGSSLMODE=disable`).
- Если секрет случайно стал публичным, замени его и обнови переменную в Render.

## 💻 Локальный запуск

Нужен **Node.js 22 или новее**.

```bash
npm install
npm start
```

Перед запуском задай те же переменные окружения, что указаны в разделе установки. По умолчанию сервер использует порт `3000`.
